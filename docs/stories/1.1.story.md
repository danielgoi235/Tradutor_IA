# 📖 Story 1.1: Anfitrião Cria Sala

**Epic:** 1 - Sinalização e Acesso
**Status:** 🟡 READY
**Priority:** 🔴 CRITICAL
**Story Points:** 5

---

## 🎯 User Story

```
Como ANFITRIÃO
Quero CRIAR uma sala com um clique
Para que meu CONVIDADO receba um código único para conectar
```

---

## ✅ Acceptance Criteria

- [ ] Clico botão "Criar Sala" na interface
- [ ] Sistema gera código alfanumérico único (8 caracteres, ex: A1B2C3D4)
- [ ] Código é copiável (botão com ícone copy)
- [ ] Firestore cria documento `rooms/{roomId}` com status "waiting"
- [ ] UI mostra "Aguardando convidado..." com animação de loading
- [ ] WebRTC Peer Connection é iniciado localmente
- [ ] SDP Offer é gerado e salvo em Firestore
- [ ] Usuário não consegue avançar sem preencher nome e idioma
- [ ] Código permanece válido por 30 minutos
- [ ] Após 30 min sem convidado, sala é deletada automaticamente

## 📝 Notas de Implementação

1. **generateRoomId():** Usar crypto.getRandomValues() ou biblioteca `nanoid`
   ```typescript
   // Opção 1: Custom
   const chars = 'ABCDEFGHJKMNPQRSTUVWXYZ23456789'; // sem I, O, 1, l

   // Opção 2: nanoid
   import { nanoid } from 'nanoid';
   const roomId = nanoid(8).toUpperCase();
   ```

2. **Expiração:** Usar Firestore TTL (Time To Live) se disponível, ou Cloud Function agendada

3. **Validação de uniqueness:** Antes de criar, checar se roomId já existe
   ```typescript
   const exists = await getDoc(doc(db, 'rooms', roomId));
   if (exists.exists()) return generateRoomId(); // Retry
   ```
