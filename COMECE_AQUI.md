## 🎯 Passo 1: Criar Repositório no GitHub

Cria um repositório novo na sua conta GitHub e sobe toda documentação.

### Execute:
```bash
node create-github-repo.js
```

### O script vai pedir:
```

? Nome do repo: [ENTER para Tradutor_IA]
? GitHub Personal Access Token: [seu-token-ghp_...]
```

### Resultado:
```

✓ Documentação adicionada

```

## 🚀 Passo 2: Deploy Automático no Vercel

Faz build, push, deploy tudo automaticamente!

### Execute:
```bash
node aiox-deploy.js
```

### O script vai pedir:
```
? Twilio Account SID: [seu-sid-AC...]
? Twilio Auth Token: [seu-token]
? Twilio Phone Number: [+1234567890]
? Google Cloud Project ID: [seu-projeto]
? Gemini API Key: [seu-key-AIzaSy...]
? GitHub Repo: [seu-usuario/Tradutor_IA]
? GitHub Personal Access Token: [seu-token-ghp_...]
? Vercel API Token: [seu-token-vercel_...]
```

### O script faz:
```
✓ Build Backend
✓ Build Frontend
✓ Push para GitHub
✓ Deploy Backend no Vercel
✓ Deploy Frontend no Vercel
✓ Configuração automática
✓ URLs finais
```

### Resultado:
```
✅ Backend rodando:   https://seu-usuario-backend.vercel.app
✅ Frontend rodando:  https://seu-usuario-web.vercel.app
✓ Pronto para usar!
```

## 🆘 Troubleshooting Rápido

### "Token inválido"
```
Gere novo token (GitHub/Vercel)
Copie sem espaços extras
```

### "Build falhou"
```
Verifique Node.js instalado
npm --version (deve ser 14+)
```

### "Deploy travado"
```
Deixe rodando, Vercel demora
Pode estar compilando
Aguarde 5-10 min
```
